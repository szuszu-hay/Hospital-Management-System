# Hospital Management System
A functional system for doctors, nurses, and patients that is built with HTML, CSS, JS, Python Flask, and MySQL for database.

## Features
- Role-based Access Control
- Sign Up
- Login
- Reset passwords
### Doctors
- Assign treatments and diagnosis
- Book appointment for patients
- View patient details
- View upcoming, vitals saved, missed, or completed appointments
- View full details of completed appointments
- Create appointment slots (for patients to book)
- Edit slot date and time
- View and edit own personal details
### Nurses
- Add patients
- Add patient vitals
- View patient list
- View upcoming and missed appointments
- View and edit own personal details
### Patient
- View medical records
- Book appointments by choosing a department, doctor, and slot
- View upcoming appointments
- View and edit own personal details
